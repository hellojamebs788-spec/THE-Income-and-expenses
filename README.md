# 💰 Easy Spend - Web App บันทึกรายรับรายจ่าย

เว็บแอปพลิเคชันบันทึกรายรับ-รายจ่าย ดีไซน์สวยงาม ทันสมัย ใช้งานได้ดีทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ เชื่อมต่อฐานข้อมูลคลาวด์ผ่าน Supabase

## 🚀 ฟังก์ชันการใช้งาน
- บันทึกรายการรายรับ (+) และรายจ่าย (-)
- คำนวณยอดรวมรายรับ รายจ่าย และยอดเงินคงเหลืออัตโนมัติ
- แสดงประวัติรายการเรียงจากล่าสุด พร้อมวันเวลาที่บันทึกข้อมูล
- ลบรายการออกจากหน้าเว็บและฐานข้อมูลได้

## ⚙️ วิธีการเปิดใช้งานบน GitHub Pages
1. สร้าง Repository ใหม่บน GitHub ของคุณ
2. อัปโหลดไฟล์ `index.html`, `style.css`, `script.js` และ `README.md` ขึ้นไป
3. ไปที่แถบ **Settings** ของ Repository -> เลือกเมนู **Pages** ด้านซ้ายมือ
4. ในหัวข้อ Build and deployment ตรงส่วน **Branch** ให้เปลี่ยนจาก `None` เป็น `main` หรือ `master` แล้วกด **Save**
5. รอระบบประมวลผลประมาณ 1 นาที คุณจะได้ URL สำหรับเปิดใช้งานและแชร์ลิงก์ไปเปิดในโทรศัพท์มือถือได้เลยครับ!
